# kyudo_score

弓道の的中掲示板をカメラで撮影し、YOLOによる物体検出で◯✕をリアルタイムに認識・スコア管理するシステムです。

## 使い方

### カメラモード（通常運用）
```bash
python main.py
```

### 画像ファイルモード（動作確認用）
```bash
python main.py test_image.png
```

## 入力映像について

**入力映像は掲示板のエリアのみにトリミングしてください。**

本システムは「映像内に◯と✕以外の余計なものが映り込まない」という前提で設計されています。
名前や数字などの文字が映り込むと誤検知の原因になります。

トリミングには **OBS のクロップフィルタ** を使用することを推奨します。

## アーキテクチャ（目標構成）

```
[的場PC-1] ──┐
[的場PC-2] ──┼──→ [中央サーバー] → スコア管理・集計・表示
[的場PC-3] ──┘
```

複数の的場にそれぞれPCを設置し、各PCが認識したスコアデータを中央サーバーに送信して一元管理することを目標としています。
現状はスタンドアロン動作のみ対応しています。

## CSVデバッグ出力

`ScoreManager.save_csv()` を呼び出すとスコアをCSVに保存できます。
通常運用では使用せず、デバッグ目的で手動で呼び出します。

## 既知の課題

- 学習データが不足しているため、誤検知が発生することがあります
- 掲示板の一部しか映っていない場合、グリッド判定がずれることがあります

## モデルについて
的中掲示板の◯✕を認識するYOLOモデルを独自データセットで学習させています（train.py）。学習データの不足により現状は誤検知が発生するケースがあり、データ拡充を課題としています。

## 設定（config.py）

| パラメータ | 説明 | デフォルト |
|---|---|---|
| `video_source` | カメラID | `2` |
| `conf` | 検出信頼度しきい値（高いほど厳しく） | `0.75` |
| `num_targets` | 射手の人数（列数） | `5` |
| `num_shots` | 射数（行数） | `4` |
